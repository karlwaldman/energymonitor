Analytics privacy

EnergyMonitor uses PostHog to count visits to its public dashboard. This integration is cookieless: a random identifier stays in memory for one page load. No cookies, persistent visitor identifiers, person profiles, session recordings, map settings, search text or form contents are sent. URLs exclude query strings and fragments; referrers retain only the website hostname.

Do Not Track and Global Privacy Control disable this integration. Desktop, development and preview hosts are excluded.
